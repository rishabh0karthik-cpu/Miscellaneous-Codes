# Carcosa: Field of Echoes

Carcosa alpha 1 is a horror-themed Minesweeper game built with Pygame.

## Run

```bash
python -m pip install -r requirements.txt
python Code_1.py
```

## Controls

- `Space`: Start the mission or advance dialogue
- `WASD` / arrow keys: Move one tile
- Right-click: Flag or unflag an unexplored tile
- `H`: Open the field manual from the main menu
- `R`: Restart after victory or death
- `Esc`: Return to the menu
